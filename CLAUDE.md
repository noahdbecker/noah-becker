# noah-becker — personal vita site

Astro 7.3 static one-pager. Before doing anything, read `docs/README.md`,
then `docs/design.md` for visual work or `docs/content.md` for content work.

- All content: `src/data/profile.ts`
- Tokens + grid system: `src/styles/global.css`
- Log structural decisions in `docs/decisions.md`
- `npm run dev` / `npm run build`
